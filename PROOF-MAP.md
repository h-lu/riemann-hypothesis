# Proof map for the pinned Lean Riemann hypothesis submission

The main mathematical route in the pinned source supplies a one-sided bound on a smoothed Dirichlet-character family, $G_\Lambda(x)\le x^{1/2+9\varepsilon}$, on arbitrarily late windows $[Y,Y^{3/2}]$. Theta matching supplies the row and column inputs. Divisibility gives an integral map into a shifted dual lattice and one direction of a slope comparison. A frame estimate for the Harder–Narasimhan filtration gives the other direction. The two comparisons yield the per-unit inequality that enters the smoothed sum. A Laplace-transform argument then excludes zeros to the right of $1/2$ for primitive characters, and the last wrappers use Euler factors and functional equations. This is a static source map. The coverage section gives the extent of the body reading and the dependencies still open for this review.

The source for the former Deicyde project is pinned at `371a1a26d5e17f604428e3a8ce6ce341cf517434` in the original public GitHub repository. GitHub identifies `h-lu/riemann-hypothesis` as a public fork. Its orientation commit `85d1a9b0a522b7ffc90d411a904a334c3e3e08ce` has the source pin as its parent and changes only `READING-NOTES.md`. The `src` Git tree at both commits is `24df20b62d9976ccd20da819bc20b16f808f0fdd`. The code links below all address the original repository at the source pin. ### 2. Divisibility turns matched rows into arithmetic lattice maps

**The cohomological cost of division.** Write $x$ for the scale, $L_{\rm sc}=x^\varepsilon$, $b=\exp(x^\varepsilon)$, and $B_0=fmbL_{\rm sc}$. The chosen host supplies a bound $\sqrt b$ on the log-weighted finite lengths recorded in `vvTerm`. `vvRecord` turns the bounds on finite prime sums into summability and the same bound on the infinite sum. At a lift $j\in\{1,\ldots,m\}$, `LinkN_at` gives
$$
 \eta_j\le d_{Z,0}(j)
 \left[C\big(fmbL_{\rm sc}^{\,2}+(\log x)^2N_c\big)
      +\sum_\ell {\rm vvTerm}(\ell)\right],
 \qquad
 \eta_j=\sum_{w\in{\rm supp},\,\mu(w)\ne\mu_0}
       {\rm lwP}(w)\,e(w)\,\eta_J(j,w).
$$
Here $e(w)$ is the ramification index and $N_c$ is the nonnegative cloud budget in the record, built from the rank budget. `SmallLevelRankEq` replaces $d_{Z,0}(j)$ by $D_0$. For large $x$, $(\log x)^2\le x^\varepsilon$ and $\sqrt b\le b\le B_0$. The resulting `DIVinN_at` inequality is
$$
  \eta_j\le D_0 (|C|+1)x^\varepsilon(B_0+N_c).
$$
`inEta3_num` transfers it to the finite weighted sum on the twisted places of the *same* package, using the equality of numerical records and the inclusion of that place set in the support. $$
